# Sam Launcher - TizenBrew module

Glossy custom launcher for Samsung Tizen TV.

## Install via TizenBrew
TizenBrew -> Module Manager -> Add GitHub Module -> `<github-user>/sam-launcher`

## Tiles
Plex, Netflix, FreeTube (via TizenBrew), YouTube, Disney+, Hulu, Spotify, HDMI 1, HDMI 2, HDMI 3 (ARC), All Ports, Samsung Home (recovery).

Soundbar audio stays on Receiver (HDMI ARC). No DNS blocking, no firmware changes.
